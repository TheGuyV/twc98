FEATURES

코인 넣고, 시작 누르고, 킥오프

두 사람이 함께 팀 선택 화면에 도착합니다. 나라는 각자 고르고, 1P 대 2P 친선 경기가 두 PC에서 똑같이 진행됩니다.

  • 팀 선택까지 자동

    코인과 시작 버튼은 런처가 알아서 누릅니다. 팀 선택 화면부터는 직접 하면 됩니다.

  • 골키퍼 멈춤 버그 수정

    골키퍼가 공을 잡은 채 경기가 멈춰 버리던 고질적인 버그를 고쳤습니다.

  • 관전

    경기 중에도 최대 4명까지 들어와서 볼 수 있습니다. 진행 중인 경기를 받아서 그대로 따라갑니다.

  • 인터넷에서도 부드럽게

    두 사람의 회선에 맞춰 런처가 알아서 조절합니다. 경기 중에도 계속. 이름과 핑은 화면 아래 얇은 막대에 나옵니다.

  • 내 키 그대로

    처음 한 번 싱글게임에서 키를 정하면 끝. 온라인 경기 중에는 Tab, F1~F12, 일시정지, Esc가 잠겨서 실수로 경기가 멈추지 않습니다.

  • 서버 또는 직접 연결

    온라인 서버로 하거나, 내 PC로 방을 열어 친구가 내 주소로 들어오게 할 수 있습니다.

경기장까지 네 단계

  1. 압축을 폴더에 모두 풀기

    압축 파일 안에서 바로 실행하지 마세요. 폴더 이름에 한글이 있어도 됩니다.

  2. 게임 롬 넣기

    가지고 계신 twcup98.zip, stvbios.zip(MAME 0.289 기준)을 런처의 롬 설정 창에 넣으면 mame\roms에 알맞게 복사하고 확인합니다.

  3. TWCLauncher.exe 실행

    연결 방식을 고르고 닉네임을 넣은 뒤 [접속]. 처음에는 키 설정용 싱글게임이 켜집니다.

  4. 준비, 그리고 킥오프

    [방 만들기] 또는 [참가]. 상대가 [준비]하면 방장이 [시작]합니다. 방장은 1P, 참가자는 2P입니다.

온라인 서버

그대로 [접속]하면 됩니다. 방, 채팅, 경기가 서버를 거쳐서 포트를 열 필요가 없습니다.

직접 연결 · 방 열기

내 PC가 방이 됩니다. 다른 집에서 들어오려면 공유기에서 TCP 7210 포트를 열고, Windows 방화벽 창에서 허용해 주세요.

비상업 팬 프로젝트입니다. 테크모 월드컵 98(Tecmo World Cup '98)은 테크모의 저작물이며 세가 ST-V 기판용 게임입니다. 이 사이트는 테크모, 코에이테크모, 세가와 관련이 없습니다.

에뮬레이터: 공식 MAME 0.289 배포판을 수정 없이 사용합니다 (GPL-2.0). 버그 수정은 함께 실행되는 스크립트로 적용됩니다. 소스: github.com/mamedev/mame, 태그 mame0289. 런처와 넷플레이 스크립트(Lua)는 이 사이트에서만 배포하며, 허락 없이 수정하거나 재배포할 수 없습니다.
